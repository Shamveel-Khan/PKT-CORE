# `corpus/` — sample policy, provenance and reproduction

This directory documents the **1,026 distinct Packet Tracer containers** used to
reverse-engineer the format. The binaries themselves are **not** committed to
this repository; their identity is. See [Why?](#why) below.

| File | What it is |
| --- | --- |
| [`CORPUS_INDEX.tsv`](CORPUS_INDEX.tsv) | The corpus manifest: every file's name, size, SHA-256, decode status, XML root tag and source tag. **This is the authoritative record.** |
| [`SOURCES.tsv`](SOURCES.tsv) | Source tag → upstream URL → license status. |
| [`INTERNET_SOURCES.md`](INTERNET_SOURCES.md) | Full harvest provenance log: queries used, acceptance criteria, per-batch notes. |
| [`fetch_corpus.py`](fetch_corpus.py) | Reproduces the corpus locally from upstream and verifies it against `CORPUS_INDEX.tsv`. |
| [`samples/`](samples/) | Self-authored, GPL-3.0 sample containers that *are* committed, so the repo is testable out of the box. |

## Reproducing the corpus

```console
$ python3 corpus/fetch_corpus.py --out corpus/files
```

This shallow-clones each upstream, locates the files whose SHA-256 matches the
manifest, copies them into `corpus/files/`, and fails loudly on any mismatch.
What you end up with is byte-identical to what the reverse engineering ran against.

## Why the binaries are not committed

1. **They are not ours.** The corpus is 1,026 files harvested from ~40 public
   repositories and archives. Only 12 of 40 upstreams ship a `LICENSE` at all;
   under default copyright the remaining 28 are all-rights-reserved. This project
   is GPL-3.0, and GPL-3.0 does not grant us the right to relicense third-party
   works. Redistribution would be a licensing violation.
2. **One subset is specifically off-limits.** `bbent-cis202-PTA2011__*` (60 files)
   is the **official Cisco Networking Academy** curriculum (IT-Essentials /
   CCNA-1). That is Cisco-copyrighted course material and is not redistributable
   under any open-source licence. It is recorded in the manifest by hash so the
   research is reproducible, and `fetch_corpus.py` will **skip it by default**.
3. **The repo already made this call.** `.gitignore` has excluded `*.pkt`/`*.pka`
   since the project began. Reversing that for 220 MB of third-party binaries
   would be a regression, not an improvement.
4. **Reproducibility is better served by hashes than by blobs.** The manifest pins
   exact content; anyone can verify they have the same corpus. A pile of opaque
   binaries in git history does not.

If you hold rights to a subset and want it vendored here, open an issue — self-
authored samples under GPL-3.0 are welcome in `samples/`.

## What *is* committed

`corpus/samples/` contains containers **generated by this project's own tooling**
(`tools/lab_api.py`), licensed GPL-3.0 like the rest of the repository. They are
excluded from the `*.pkt`/`*.pka` ignore rule explicitly, and they cover both
document roots:

* `PACKETTRACER5` — an ordinary `.pkt` lab
* `PACKETTRACER5_ACTIVITY` — a scored `.pka` activity
